# Обработка заданий ЕГЭ по математике

## Описание
Проект предназначен для автоматизированной обработки заданий тренировочного варианта ЕГЭ по математике

## Функциональность
- Скачивание PDF-файла с сайта-источника.
- Извлечение условий заданий из PDF.
- Извлечение и сохранение изображений заданий.
- Преобразование условий в LaTeX с помощью Gemini API.
- Экспорт заданий в Excel.
- Создание ZIP-архива с Excel-файлом и изображениями.
---

## Стек технологий
- Python
- PyMuPDF
- OpenPyXL 
- Google Gen AI

## Локальное развертывание проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ToSky26/gemini_project.git
cd gemini_project
```

### 2. Создать виртуальное окружение
```bash
python3 -m venv venv
```

### 3 Активировать виртуальное окружение.
```bash
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Настроить Gemini API
Создайте файл .env в корне проекта и добавьте API-ключ:

```bash
GEMINI_API_KEY=ваш_api_ключ
```

### 6. Запуск программы

```bash
python3 main.py
```
